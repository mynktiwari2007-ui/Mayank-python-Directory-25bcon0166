# Python Dictionary Program

## About

This project contains a Python program, `dictionary.py`, that demonstrates how to create and access a dictionary.

The program stores student information, including name, age, and marks, using key-value pairs.

## File Structure

```text
python-beginner/
└── dictionary.py
```

## How to Run

### Prerequisites

* Python 3 installed on your computer.

### Steps

1. Download or clone the repository.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python dictionary.py
```

Alternatively, use:

```bash
python3 dictionary.py
```

## Learning Objectives

This program helps beginners understand:

* Creating dictionaries in Python.
* Storing information as key-value pairs.
* Accessing values using dictionary keys.
* Using `print()` to display dictionary data.
* Representing structured information in Python.

## Concept

A dictionary is a Python data structure that stores information as key-value pairs.

For example:

```python
student = {
    "name": "Rahul",
    "age": 20,
    "marks": 85
}
```

Here, `name`, `age`, and `marks` are keys, while `"Rahul"`, `20`, and `85` are their corresponding values.

## Purpose

This project helps beginners learn how to store and retrieve related information using Python dictionaries.
